# 📊 Mobile Sales Dashboard Using Power BI

## 📌 Project Overview

The Mobile Sales Dashboard is an interactive Power BI project designed to analyze and visualize mobile sales data. The dashboard provides actionable insights into sales performance, revenue trends, customer purchasing behavior, and brand-wise performance through dynamic visualizations and KPI tracking.

## 🎯 Objectives

- Analyze overall sales performance
- Monitor revenue and quantity sold
- Identify top-performing mobile brands
- Track monthly and yearly sales trends
- Understand customer purchasing patterns
- Support data-driven business decisions

## 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning & Transformation

## 📈 Key Dashboard Features

- Interactive Filters and Slicers
- KPI Cards for Quick Insights
- Revenue Analysis
- Brand-wise Sales Performance
- Monthly Sales Trend Analysis
- Customer Insights
- Regional Sales Analysis
- Dynamic Visualizations
